# SunJudge 操作说明

## 主说明与作业附件

教师在作业基本信息下方的“主说明”卡片编写作业要求。主说明始终独立，不属于作业资料，也不占用附件名额；导入主说明Markdown请使用该编辑器的导入功能。

“作业资料”只管理附件，计数为`0/4`，最多4个UTF-8编码的`.py`或`.md`文件，单个不超过1MB。文件名和用途均可在列表中填写，用途选填、最多120字；文件名须保留正确后缀且不能重名，不可包含路径。上传同名文件会替换表单中的同名附件并保留用途，保存作业后生效。

资料区提供“新建”和“上传”两个入口。“新建”直接打开Markdown附件编辑器，可填写文件名和用途、编写正文；未填写后缀时自动补上`.md`，不能覆盖同名附件。“上传”打开文件选择对话框，接受`.py`和`.md`。两种方式都先加入当前表单，保存作业后才生效；取消新建不会添加空文件。

学生始终先看到独立主说明，下面的“作业附件”卡片列出文件名、用途及预览/下载操作；没有附件时不显示此卡片。“预览”和“下载”排在同一行；点击预览会弹出与教师批改时相同的在线预览窗口，支持Markdown正文或Python高亮代码，窗口底部可关闭、下载或复制内容，不会替换主说明。正文内的`[代码](./starter.py)`等相对附件链接也可打开附件预览。Python附件不会自动运行或填入学生提交，下载框架后应按提交项的命名规则改名并提交。

预览窗口标题栏与底部采用相同主题底色。“复制内容”复制当前文件的原始文本：Python源码或Markdown源码，保留缩进、空行和Markdown语法，不复制高亮/排版后的HTML。加载中、读取失败或不支持文本预览时不可复制。浏览器需支持并允许剪贴板写入；若复制失败，可重试或下载文件。

教师编辑页的附件操作列直接提供预览、编辑（仅Markdown）、下载和移除图标，全部在同一行，不另外显示学生端预览区域。尚未保存的附件也可预览和下载。

## 在线编辑Markdown附件

1. 在资料列表点击Markdown文件的编辑图标，窗口明确显示“附件”和正在编辑的文件名。
2. 可以修改文件名、用途及正文，使用图片库、插图、导入和预览工具；`Ctrl+S`或`Command+S`可应用当前编辑。
3. 点击“应用到作业”仅更新该附件；“取消”放弃本次附件窗口内的修改。
4. 回到作业编辑页保存或发布，才会写入作业。已发布作业仍由教师选择是否要求学生重交。

附件编辑不写入主说明草稿，也不会改动其他附件。主说明沿用服务器草稿自动保存和冲突保护；附件正文随作业表单保存，不单独自动保存，关闭或刷新尚未保存的表单可能丢失附件编辑。

升级仅取消旧版自动生成的主文件标记，保留原主说明、说明草稿和所有附件的内容、下载ID及配图，不用附件覆盖原说明。历史作业若有5个附件，升级保留全部供查看和下载，再次保存附件列表前须整理到4个以内；学生提交和成绩不变。

## Markdown配图与图片库

Markdown编辑器支持选择图片库中的图片，以及上传、粘贴截图和拖拽PNG/JPEG图片。单图不超过5MB；教师库总容量500MB，学生库30MB，双方最多1000张。直接插入的图片自动加入本人图片库。

从本地导入`.md`只导入正文，不会同时上传本地图片。请使用编辑器上传配图或插入图片库链接。教师主/附Markdown中的图片必须属于教师本人的图片库；被已保存作业、草稿或历史提交引用的图片不能删除。

取消附件编辑不会删除已经上传到个人图片库的图片；未被引用的图片可以在图片库管理中删除。库内图片可复用，无需为不同作业重复上传。

## 学生提交与补交

保存在线草稿或上传文件不等于提交。必交文件准备齐全后，点击“确认提交作业”；确认后才进入批改流程。

作业截止后，教师可以在提交列表中为某位未完成的已注册学生点击“允许补交”。该学生刷新作业列表后，截止日期旁会显示“待补交”，并可上传、在线编辑及确认提交。教师撤销授权后，按原截止规则限制提交。

成功确认一次后补交授权消耗，“待补交”消失，提交日期按该次确认时的作业截止日期显示，并带“补交”标记；完成、提交速度等指标使用这个有效日期，实际提交时间仍单独保留。已发布反馈的作业需要先由教师退回后才可重新提交。

## 修改已发布作业

- “保留已有提交”：文件、完成状态和成绩不变，适用于延期、修订说明或调整附件。
- “要求学生重交”：清空批改结果，保留文件和草稿供学生修改后重新确认；截止时间已过时，还需延期或给相关学生开放补交。

保存草稿不会提前清空成绩，通过作业列表重新发布时也会出现相同选择。

## Excel名单导入

教师选择Excel后，系统显示解析人数，再选择“追加”或“覆盖”。追加只新增编号；覆盖更新或移除未注册名单项。已绑定账号的学生保留，姓名或学号发生冲突时取消整次导入。

## 成绩折算与批量导出

导出时的比例因子默认1，允许0到1000的有限数字。最终导出成绩为原始成绩乘比例因子，四舍五入保留两位小数；CSV分列保存原始成绩、因子和结果，不改写系统中的成绩或统计。

ScoreManagerCLI只导出已复核或已发布的最终成绩。可复制全部命令到CLI，执行后使用`save`保存；同分学生可合并为普通`brd`或实验`lab brd`。

下载的`scoremanager_commands.txt`末尾包含`exit -s`，用于保存并退出。将TXT放入ScoreManagerCLI目录，在该目录打开PowerShell，替换课程名后执行：

```powershell
Get-Content -LiteralPath "scoremanager_commands.txt" | python main.py "课程名"
```

命令可能是累加记分，请核对课程、学生编号和比例因子，不要对同一批成绩重复导入。平台仅生成文本，不自动运行CLI。

## 评测结果与标签

列表用等长的“作业”“实验”标签区分类型；后端作业类型和评分逻辑不因标签简称而改变。

暂无程序评测结果时，可尝试重测或检查测试用例及Docker环境；AI结果未生成时可由教师人工复核。AI评分只是建议，教师发布后学生才能看到最终成绩与反馈。
