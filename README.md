# SunJudge

面向高校教师与学生的课程作业平台，将作业发布、文件提交、Python 自动评测、AI 辅助批改、教师复核与成绩导出串成完整的教学流程。

**上线地址：[judge.xuelongsun.cn](https://judge.xuelongsun.cn)**

适用于 Python 编程作业、Markdown 实验报告，以及同时提交代码和报告的课程作业。

## 解决哪些教学痛点？

| 常见问题 | SunJudge 的处理方式 |
| --- | --- |
| 作业散落在聊天群、邮箱和文件夹，难以核对谁交了、谁没交 | 按教学班和名单集中收集，展示提交、逾期和批改状态 |
| 文件名、类型和大小不统一，收齐后还要手工整理 | 教师设置提交规则，学生上传时自动校验，并明确区分必交项与选交项 |
| 代码需要逐份运行，报告需要反复对照评分标准 | Python 测试用例自动评测，DeepSeek 按教师评分标准提供分项建议与反馈 |
| 同一课程每年重建作业、反复上传配图 | 作业设置可迁移到另一教学班，师生个人图片库支持跨作业复用 |
| 成绩统计、批改反馈和录入成绩需要重复操作 | 集中复核与发布反馈，提供进度概览、CSV 和 ScoreManagerCLI 命令导出 |

## 项目特色

- **围绕真实教学名单组织作业。** 教师导入名单，学生使用真实姓名和个人邀请码注册，支持一个账号绑定多个教学班。
- **代码与报告放在同一份作业里。** 每份作业可设置多个提交项，分别指定文件后缀、大小、命名规则、是否必交及评分权重。
- **自动评测与教师判断结合。** 程序评测展示用例结果，AI 提供评分建议；教师可逐文件复核、调整分数并发布最终反馈。
- **减少跨班、跨学期的重复准备。** 迁移作业时复制说明、提交规则和评测设置，目标保存为草稿，便于检查后发布；学生提交与成绩不会被复制。
- **Markdown 写作与图片管理一体化。** 在线编辑支持预览、公式、代码高亮和图片插入，教师与学生均有个人图片库。
- **可以用测试账号走完整流程。** 每班的 00 号用于教师测试，提交情况单独展示，可查看和批改，同时不影响班级统计与成绩导出。

## 主要功能

### 教师端

- **班级与名单：** 创建教学班，使用 Excel 导入学生名单，选择追加或覆盖；维护未注册名单，并查看学生注册情况。
- **作业发布：** 编辑 Markdown 说明，设置截止时间、迟交规则、总分、提交项和命名模板；可将设置迁移为另一个自有班级的作业草稿。
- **程序评测：** 为 Python 代码配置运行参数、期望输出、超时时间及分值，查看用例结果和错误输出。
- **AI 辅助批改：** 配置自己的 DeepSeek API 信息，按评分标准获得分项建议和理由，结合人工判断完成复核。
- **查看与批改：** 点击班级行进入作业列表，点击作业行查看提交情况；在线预览代码和报告、下载文件、逐文件评分、重测或退回重交。
- **成绩与反馈：** 查看完成、分数、提交速度和批改进度，发布教师评语与反馈，导出 CSV 或可复制的 ScoreManagerCLI 命令。
- **个人图片库：** 上传、预览和管理配图，在多份作业说明中复用；编辑器直接上传的图片自动入库。

### 学生端

- **加入教学班：** 使用真实姓名、教师提供的个人邀请码和密码注册；同一账号可绑定多个班级。
- **查看作业：** 查看说明、截止时间、必交/选交项、文件后缀、大小上限和命名要求，了解待提交及逾期情况。
- **提交文件：** 上传符合要求的代码或报告；Markdown 可在线编辑，也可从本地上传，完成必交文件后确认提交。
- **管理报告配图：** 在个人图片库上传和预览图片，并在自己的多份报告中复用。上传本地 `.md` 时，文中的本地图片需要通过在线编辑器上传。
- **查看反馈：** 教师发布后查看个人成绩、分项反馈与教师评语；作业被退回后按要求修改并重新提交。

管理员负责审批教师申请，并查看教师与教学班的层级信息；班级和学生名单由教师维护。

## 如何开始使用？

**教师：** 打开[平台](https://judge.xuelongsun.cn)，在“注册 / 申请”中选择教师，提交申请并等待管理员审批。通过后创建教学班、导入名单、发布作业，再将个人邀请码发给对应学生。使用 AI 辅助批改时，还需配置自己的 DeepSeek API Key、服务地址和模型。

**学生：** 向教师获取个人邀请码，例如 `OS202601-06`，使用与名单一致的真实姓名注册。登录支持真实姓名或已绑定的学生编号。进入班级后查看作业，按要求上传或在线编辑，最后点击确认提交；上传文件本身不等于完成提交。

当前自动程序评测支持 Python，核心作业格式为 `.py` 与 `.md`；具体可提交类型以教师设置为准。AI 评分只是建议，最终成绩由教师复核和发布。ScoreManagerCLI 导出只生成命令文本，由教师自行复制执行。

## 开发与自托管

技术栈：Flask、SQLAlchemy、Alembic、Vue 3、TypeScript、Element Plus；本地使用 SQLite，生产使用 MySQL，Python 评测使用 Docker。生产部署采用 Ubuntu、Nginx、Gunicorn 和 Supervisor。

本地启动后端：

```bash
cd backend
uv sync --locked
uv run flask --app app:create_app db upgrade
uv run flask --app app:create_app create-admin admin
uv run flask --app app:create_app run --debug
```

在另一个终端启动前端：

```bash
cd frontend
npm ci
npm run dev
```

按需将 `backend/.env.example` 复制为 `backend/.env`；管理员创建命令会提示输入密码。前端开发代理将 `/api` 转发至 `127.0.0.1:5000`。运行后端测试使用 `uv run pytest -q`，前端测试与构建分别使用 `npm test`、`npm run build`；接口说明见 [API 文档](docs/API.md)和[路由索引](docs/API_REFERENCE.md)。

生产升级前执行数据库迁移，再更新前端构建与后端服务。当前批改采用进程内串行队列，Gunicorn 使用单 worker；图片目前不参与 AI 视觉评分。自托管需配置 HTTPS、会话密钥与 LLM 密钥加密，并同时备份数据库和完整上传目录。请勿提交 `.env`、API Key、真实学生名单、成绩、上传文件或本地数据库。
